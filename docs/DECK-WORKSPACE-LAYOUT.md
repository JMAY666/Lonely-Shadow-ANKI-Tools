# 牌组页面布局

牌组目录与主内容之间支持拖动分隔条。目录默认宽 250 像素，范围为 190–480 像素，并为学习区域保留至少 320 像素。窗口缩小时自动收紧目录，恢复窗口宽度后还原用户选择；网页可用宽度不超过 650 像素时改为上下排列。

悬停显示左右调整光标，拖动实时更新，松开停止。分隔条可以通过 Tab 聚焦，左右方向键每次调整 10 像素，Shift 加速至 40 像素，Home/End 调到当前边界，双击恢复默认。宽度随原有目录状态保存在当前网页会话中，切换牌组或进入学习后返回保持；关闭软件后使用默认宽度。

辅助信息、账户等级、连击、每日挑战、升级进度、每日知识及统计放在学习面板下方。普通与简洁面板根据主内容的可用宽度分列，不再占用独立右栏。原有折叠状态、账户组件、统计口径和命令入口保留。

页面布局不会写入卡片或调度数据，也不更改学习队列、每日限制或现有设置。

## 切换牌组时的等待反馈

普通牌组选择使用后台事务，不显示阻塞整个应用的“正在处理”窗口。目录立即高亮目标；超过 300 毫秒仍未完成时，在学习面板原提示行显示“正在切换…”，保留原内容。此时学习、牌组工具及当前牌组统计入口暂时禁用，学习快捷键也不会进入旧牌组。失败时在原处说明并提供“重试”，也可直接选择另一个牌组。

连续选择只保留最后一个目标；数据库尚未执行的过期选择不会写入，已经开始执行的操作正常完成，过期结果不覆盖新选择。切换复用两秒内的牌组计数和今日统计；学习数据变化或完整刷新会使缓存失效，真正开始学习仍由原生队列决定到期时间及每日限额。仅计数变化不会重新创建目录和账户辅助面板；重命名、增删或层级等目录变化仍完整刷新。同步、导入等其他操作保留原有进度窗口。

`just deck-selection-test` 验证请求合并、过期结果、错误重试、导航取消、学习入口保护和缓存失效。`just deck-workspace-smoke <独立运行名>` 额外阻塞合成账户数据库超过弹窗阈值，检查无模态窗口、页面提示、连续选择、重试及原生学习入口。
